Privacy Policy — Remy Meal Planner

Last updated: September 25, 2026

Remy Meal Planner is a private tool used by a single household. It is not offered to the public.

What it accesses

  • Google Calendar (read-only): upcoming events on the household calendar, used only to plan which nights to cook.
  • Google Drive (files it creates only): it uploads and updates recipe-card PDFs it generates. It cannot see any other Drive files.

How data is used and stored

Data is used only to plan meals and file recipe cards. It is stored on a private server controlled by the household. It is never sold or shared, and it is never used for advertising.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
